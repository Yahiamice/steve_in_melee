# YAHIAMICE'S MELEE STEVE

### Steve's been ported from Smash Bros Ultimate to Melee! Comes with 9 alts and a custom stage, Skyblock

1) YOU'LL NEED:

    - Your own **Smash Bros Melee NTSC v1.02 ISO (GALE01)**, checksum 0e63d4223b01d9aba596259dc155a174
    - A patcher that can apply .xdelta patches:
      - Windows:      Delta Patcher  https://github.com/marco-calautti/DeltaPatcher/releases
      - Mac / Linux:  xdelta3 https://kotcrab.github.io/xdelta-wasm/
  
2) How to patch & play
   - Download the latest release of the patch file *Melee_Steve_v1.20.xdelta* in the releases to the right
   - In your patcher, select your Melee v1.02 ISO as the original file and the *Melee_Steve.xdelta* as the patch
   - Click Apply Patch, when it's successful you can run the iso through Dolphin!
   - Press L+R+A to show steve in the CSS
  
3) OPTIONAL SLIPPI INSTRUCTIONS:
 - Go to Slippi Launcher -> Settings -> Game -> set your Melee ISO file to the new steve-ified .iso you just patched.
 - If crashes happen try enabling the "Skip Slippi SSS" gecko code, also report crashes by sending your replay files in the issues tab
 - DO NOT GO RANKED OR UNRANKED!!! Only use it in direct matches w/ people that are also running the same .iso! Else you might get desyncs (or worse, banned)
 - Skyblock is built on FD and the slippi patches that freeze FD's background might not apply there, so sorry if there's desyncs!
